---
title: "ReARM 26.11.59: Security Patch Release for java4shell"
date: "2026-11-23"
---

We're announcing a security patch release of ReARM [v26.11.59](https://github.com/relizaio/rearm/releases/tag/26.11.59). Detailed information is available on its [release view](https://demo.rearmhq.com/release/show/a714bafa-0a00-47c9-9508-c471d0a8770b) on the ReARM Demo instance. All ReARM Pro instances have already been upgraded to this release. **We recommend that all ReARM CE installations upgrade to 26.11.59 for security reasons.**


**java4shell (CVE-2026-114938)**

The backend and Keycloak now run on fixed JDK builds, and the Helm chart defaults point to the fixed images of the backend, Keycloak and Dependency-Track. The Base64 intrinsic is turned off in the Flyway migration container.


**Other Security Fixes**

This release also clears CVE findings across ReARM's images: zlib, org.json and Guava in the backend; guava and mariadb-java-client in Keycloak; Alpine OpenSSL and zlib in the UI image; base-image and npm findings in Rebom Backend, which now bundles rearm CLI 26.11.10 built on Go 1.26.11; and the PostgreSQL client, Go standard library, x/net and musl in Cloud Backups. The OCI Artifact Service is built with Go 1.26.11, and the PostgreSQL 17 image moves to PostgreSQL 17.12 on Ubuntu noble-20261110.1 with all OS packages upgraded. The Helm chart pins every image to its patched release.


**Agent Task Boards**

Split tasks now carry their parent's reviewed design, so a child can go straight to the build role. A role can request a split, and every split pins the reviewed design. A design checkpoint before the build role lets the coordinator split the task or send it on, and an answer that changes the design is reviewed again before the asker continues. Board documents can optionally be included in notifications.


**Statistics Page**

Organization totals now include users without a role.


**Bug Fixes**

A COMPONENT or BRANCH scope VEX now applies only to the release it was uploaded to, and the upload scope tooltip matches the COMPONENT default. Creating a component from a VCS URI works correctly, and `addreleases` batch processing is fixed. The nginx proxy timeout for the programmatic API is configurable, with a default of 600 seconds, so long-running calls are no longer cut off. On agent task boards, the task Reopen button opens its confirmation again, and applying a board file checks the coordinator checkpoint against the API key, not a person. ReARM Pro's license seat handling is fixed: the over-license banner counts total users against the combined limit, and the seat checks are faster and better worded.
