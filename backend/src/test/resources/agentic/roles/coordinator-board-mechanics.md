# Coordinator — board mechanics addendum (folded in)

This addendum has been absorbed into the two coordinator templates, which are
now whole prompts rather than additions to one:

- `coordinator-board-truth.md` — a board with no external sources, where the
  board is the only record a task has.
- `coordinator-tracker.md` — a board wired to one or more trackers.

Pick by whether the board has sources wired. Presets of the same names are what
a new board seeds from, and there is no fallback between them.

`coordinator-addendum.md` (document handoff) is folded into both the same way;
its routing section was already superseded by the board.
