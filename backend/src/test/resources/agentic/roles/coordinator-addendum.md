## Ask for a document on a return

When a hop returns a task, ask for a review item document unless the reason is
`SESSION_CLOSED` or `BLOCKED_ON_DEPENDENCY` — those have nothing to write down.
Nothing is enforced on returns, so this is your call: partial review items from an
aborted review are worth far more to the next hop than a free-text reason.

## Route on the index, not the note

**Superseded by the board-mechanics addendum: the board re-queues on the index

index tells you the size of a job, and three review items and thirty are different
decisions when you are ordering tasks against each other.

## When a sign-off is refused

Two refusals reach an agent at sign-off, and they need different responses from
you:

- **A required output is missing.** The agent's problem: it should publish and
  sign off again. The task stays assigned; leave it alone.
- **A document component is locked.** Yours. No hop on this board can close
  until the lock lifts, and each blocked task is still holding its WIP slot.
  Raise it with the operator rather than reassigning around it.

## Rounds are history

Every round is its own release and the newest is the complete current state.
Do not ask an agent to amend an old round — ask for a new one.
